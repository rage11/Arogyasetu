Arogyam – Your Bridge to Better Health
Arogyam is a clean, modern web portal designed to simplify medical appointments and enhance the patient-doctor experience with love, care, and tech.
*Project Status: In Progress – Homepage and Appointment Booking page live*

Project Structure (Currently Live)

- `index.html` – Elegant homepage introducing ArogyamSetu with navigation and purpose.
- `appointment.html` – User-friendly appointment booking form.
- `styles.css` – Stylish and responsive CSS to give the portal a professional touch

Features (Live & Upcoming)

-  Beautiful homepage UI
-  Appointment booking page with form
-  Doctor & patient login system
-  Admin dashboard to manage schedules
-  Email/SMS appointment confirmations
-  Smart filters for doctor search (by specialization, availability)
